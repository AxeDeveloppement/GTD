## 2. Architecture & Rôles
**Architecture en 3 projets (STRICT) :**
*   `PersonalGTD.Shared` : Bibliothèque partagée contenant TOUS les composants Blazor, pages, layouts, modèles de données et services métier. C'est le cœur du projet.
*   `PersonalGTD.Web` : Hôte Blazor WebAssembly uniquement (Program.cs, middleware, DI, configuration Supabase). Aucun composant UI ne doit s'y trouver.
*   `PersonalGTD.Android` : Hôte MAUI Hybrid pour Android (MauiProgram.cs, plateforme native, notifications, Deep Linking OAuth). Aucun composant UI ne doit s'y trouver.

**Backend :** Supabase (PostgreSQL + Auth Gotrue) avec authentification Google OAuth.

## 4. Format d'Appel des Outils MCP (ai-engine)
Lors des appels d'outils MCP, tu DOIS fournir un objet JSON natif.

### REGLES STRICTES ANTI-ERREUR -32602 :
1. **PAS DE GUILLEMETS ÉCHAPPÉS DANS LES VALEURS** : Ne mets JAMAIS de `\"` à l'intérieur d'une valeur string.
   - CORRECT : `"project_id": "PersonalGTD"`
   - INCORRECT : `"project_id": "\"PersonalGTD\""`
2. **PAS DE STRINGIFICATION** : L'argument global doit être un objet JSON natif, pas un bloc de texte encodé en chaîne.

**Procédure stricte pour la Revue de Code (`ask_code_reviewer`) :**
Le serveur MCP est sur une machine Windows distante. Pour éviter les erreurs JSON -32602, tu ne dois JAMAIS utiliser `code_snippet`. Tu dois OBLIGATOIREMENT suivre cet ordre chronologique strict :

1. Utilise l'outil `execute_command` pour copier le fichier cible vers le dossier temporaire du serveur via SCP.
   *Exemple :* `scp -o BatchMode=yes "D:\projects\GTD\Chemin\Fichier.ext" axel7@100.77.221.66:E:/ai-engine/temp/review_Fichier.ext`
2. ATTENDS que l'exécution de la commande SCP soit totalement terminée et confirmée avec succès dans le terminal. Ne passe pas à la suite tant que le fichier n'est pas transféré.
3. Une fois le transfert réussi, et seulement à ce moment-là, appelle l'outil `ask_code_reviewer` en pointant vers ce fichier distant.
   *Exemple :* `{"file_path": "E:\\ai-engine\\temp\\review_Fichier.ext", "focus_area": "security"}`
