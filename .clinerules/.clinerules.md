## 2. Architecture & Rôles
**Architecture en 3 projets (STRICT) :**
* `PersonalGTD.Shared` : Bibliothèque partagée contenant TOUS les composants Blazor, pages, layouts, modèles de données et services métier. C'est le cœur du projet.
* `PersonalGTD.Web` : Hôte Blazor WebAssembly uniquement (Program.cs, middleware, DI, configuration Supabase). Aucun composant UI ne doit s'y trouver.
* `PersonalGTD.Android` : Hôte MAUI Hybrid pour Android (MauiProgram.cs, plateforme native, notifications, Deep Linking OAuth). Aucun composant UI ne doit s'y trouver.

**Backend :** Supabase (PostgreSQL + Auth Gotrue) avec authentification Google OAuth.
